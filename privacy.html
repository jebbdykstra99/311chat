Privacy (preview)

311chat is a preview on Firebase project subx-skins, site id 311chat. Short version of what this shell does today:

  • Email/password auth (Google uses the same subx-skins project when that provider is enabled).
  • Account docs live at users/{uid} with a display name and siteId of 311chat.
  • Posts are public reads. Images go to Storage under posts/311chat/{uid}/.
  • City and ZIP stay in the page. The location button runs only after you click it, and only through the browser's own prompt. No network-address lookup. No fingerprint.
  • No third-party tag manager. No ads. No assistant on the hot path.

If you want an account removed, contact the operator of this preview. This stub is not a DPA, CCPA pack, or counsel opinion.
